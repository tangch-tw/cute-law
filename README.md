# 中國科大法規導航

中國科技大學 115 學年度全校法規彙編的全文檢索介面，供本校師生查詢。

- 網址：https://tangch-tw.github.io/cute-law/
- 收錄：636 份校內規章、6,928 筆條文與點次，全文約 89 萬字，依 29 個單位分類
- 功能：白話查詢、條號定位（如「學則第 15 條」）、依單位與核定層級篩選、整份規章閱讀
- 法規縫合：與教育部《技術及職業教育法規選輯》（115 年 6 月）162 部法規對照

資料來源為學校 115 學年度全校法規彙編。本頁為該版快照，法規效力以彙編原檔與各權責單位公告為準。
本頁已設定不被搜尋引擎收錄。
